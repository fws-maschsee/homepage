# Datenschutz

**Alles läuft DSGVO-konform auf einem Server in Deutschland** — bei netcup in
Nürnberg, mit Auftragsverarbeitungsvertrag. Jede Verbindung ist
verschlüsselt. Es gibt keine Werbung, keine Weitergabe an Dritte und kein
Cookie-Banner.

Gezählt wird, wie oft eine Seite aufgerufen wird — mit Plausible, das auf
einem eigenen Server in Deutschland läuft. Ohne Cookies, ohne
Wiedererkennung, ohne Profile: Die Zählung weiß, dass eine Seite aufgerufen
wurde, und nicht, von wem.

Die förmlichen Angaben — Verantwortlicher, Zwecke, Rechtsgrundlagen,
Empfänger, Speicherdauer, Ihre Rechte — stehen in der
[Datenschutzerklärung](/docs/datenschutzerklaerung). Hier steht in kurzer
Form, wie das System gebaut ist.

## Was liegt wo

**Inhalte** — Berichte, Protokolle, Termine, Unterlagen — liegen als
Textdateien in einem privaten Archiv. Nur angemeldete Mitglieder der
jeweiligen Klasse kommen daran.

**Personenbezogene Daten** — wer wer ist, wer zu welcher Klasse gehört,
welche Adresse auf welchem Verteiler steht — liegen getrennt davon in einer
Datenbank auf dem Server. Getrennt vom Code und von den Unterlagen, damit
sie jederzeit löschbar bleiben.

## Sind die Daten sicher vor Zugriff?

Sehen kann sie nur die eigene Klasse. Jede Klasse ist ein abgetrennter Bereich; wer nicht
dazugehört, kommt nicht hinein. Wer die Schule verlässt, verliert den Zugang
und ist damit überall draußen — das ist ein Vorgang und keine Suche über
mehrere Systeme.

Wer die Server betreut, kann technisch auf die Daten zugreifen. Das ist bei
jedem System so, das jemand betreibt; wer es hier ist, steht unten.

## Kontaktdaten, Klassenlisten, Telefonnummern

Die gibt es: das **Kontaktbuch der Klasse**, ein eigener Dienst unter
[konto.fws-maschsee-test.de](https://konto.fws-maschsee-test.de). Jede Klasse
hat dort ihre Liste, als Seite und als PDF zum Ausdrucken. Warum es das gibt,
steht unter
[Warum es ein Kontaktbuch gibt](/docs/eltern#warum-es-ein-kontaktbuch-gibt).

So ist es gebaut:

- **Jeder pflegt seine eigenen Angaben, und nur die.** Anschrift,
  Telefonnummer, Kontaktadresse, die Namen der eigenen Kinder. Niemand trägt
  etwas für jemand anderen ein; es wurde nichts aus alten Listen übernommen.
- **Jedes Feld ist freiwillig, und die Freigabe gilt je Klasse.** Derselbe
  Schalter nimmt sie wieder zurück.
- **Sichtbar nur für die, die gerade zur Klasse gehören.** Das wird bei jedem
  Aufruf frisch geprüft. Wer die Klasse verlässt, verschwindet von selbst aus
  den Listen der anderen — daran muss niemand denken.
- **Nur benannte Felder, keine Freitexte.** Bei den Kindern Vorname und
  Nachname; kein Geburtsdatum, kein Geschlecht, keine Bemerkung.
- **Auskunft und Löschen sind je ein Knopf.** Eine Seite zeigt alles, was
  über Sie gespeichert ist, ein Knopf daneben löscht es vollständig.

## Anmeldung mit Google oder GitHub

Wer diesen Weg wählt, meldet sich wie gewohnt beim Anbieter an; zurück kommt
nur die Bestätigung der Identität samt Name und E-Mail-Adresse. Der Anbieter
sieht keine Inhalte der Klassenseiten, und das Passwort verlässt ihn nie.

Der Weg über E-Mail-Adresse und eigenes Passwort steht daneben. Niemand
braucht ein Konto bei einem großen Anbieter.

## Wenn eine Familie geht

Der Zugang wird gelöscht, und die Person kommt auf keine der Seiten mehr.
Bestehende Protokolle bleiben, wie ein Ordner im Klassenschrank bleibt — wer
möchte, dass sein Name aus einem Dokument verschwindet, sagt Bescheid, und
das wird gemacht.
